\section{Назначение программы}

\subsection{Назначение программы}

Программа предназначена для генерации синтетических аналитических данных набора
TPC-H и сохранения результатов в колонoчных форматах хранения данных.
Программа используется как утилита командной строки и обеспечивает подготовку
таблиц фиксированного набора с заданным масштабом генерации.

\subsection{Функции программы}

Программа обеспечивает выполнение следующих основных функций:
\begin{enumerate}
    \item генерация таблиц набора TPC-H;
    \item выбор масштаба генерации посредством параметра scale factor;
    \item выбор одной или нескольких таблиц для генерации;
    \item вывод результата в поддерживаемый формат хранения данных;
    \item управление параметрами батчирования и стратегии записи;
    \item вывод списка доступных таблиц и форматов;
    \item вывод диагностических сообщений и сообщений о ходе выполнения.
\end{enumerate}

\subsection{Сведения по эксплуатации программы}

Эксплуатация программы выполняется оператором из командной строки. Оператор
задает параметры запуска, определяющие формат результата, путь вывода, перечень
таблиц, а также дополнительные параметры записи и отображения хода выполнения.

Результатом работы программы являются сформированные файлы данных в указанном
каталоге или по указанному URI. При ошибках запуска или недопустимых параметрах
программа завершает работу с ненулевым кодом возврата и выводит диагностическое
сообщение.
