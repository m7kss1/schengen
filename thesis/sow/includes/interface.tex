Программа должна иметь командный интерфейс, позволяющий пользователю работать с программой с минимальной предварительной подготовкой. 

Интерфейс должен позволять:
\begin{enumerate}
    \item получать справочную информацию о параметрах запуска;
    \item выводить список поддерживаемых таблиц;
    \item выводить список поддерживаемых форматов хранения;
    \item задавать scale factor, формат хранения, путь вывода и набор генерируемых таблиц;
    \item задавать размер батча, стратегию записи, число потоков и дополнительные параметры форматов;
    \item получать сообщения о ходе выполнения и об ошибках.
\end{enumerate}
