    \subsection{Требования к формату входных и выходных данных}
    
    \subsubsection{Входные данные}

    Одна из основных задач программы - предоставить пользователю возможность управлять процессом генерации аналитических таблиц, не изменяя исходный код программы и не подготавливая входные файлы вручную. Пользователь должен иметь возможность задавать параметры генерации через командный интерфейс, определяя масштаб набора данных, набор таблиц, формат хранения, путь вывода, стратегию записи и параметры батчирования.
    
    Исходя из этого, входными данными для программы должны являться параметры командной строки, определяющие сценарий генерации. В состав входных данных должны входить значение scale factor, список генерируемых таблиц, формат хранения, путь или URI вывода, размер батча, стратегия записи, число рабочих потоков, емкость очереди записи, а также форматно-зависимые параметры, например параметры компрессии и логического партиционирования.

    Программа не должна требовать от пользователя наличия предварительно подготовленных табличных данных. Правила генерации, словари, распределения и зависимости набора данных TPC-H должны входить в состав программы и использоваться непосредственно в процессе генерации.

    \subsubsection{Выходные данные}
    
    Программа должна позволять пользователю сохранять сгенерированные таблицы в различных колонoчных форматах с различными параметрами записи.
    
    В зависимости от выбранной стратегии записи результатом работы программы должны являться либо отдельные файлы-партиции, либо один итоговый файл таблицы, формируемый из нескольких параллельно сгенерированных партиций. При необходимости программа должна иметь возможность записи результатов в виде набора файлов по URI, совместимому с поддерживаемой файловой системой.

    \subsubsection{Требования к пользователю}
    
    Пользователь должен иметь базовое представление о командном интерфейсе операционной системы, файловой системе и принципах работы с параметрами запуска программ. Также пользователь должен обладать базовыми знаниями о структуре набора данных TPC-H, колонoчных форматах хранения данных и назначении синтетических аналитических данных.

    \subsection{Требования к составу и параметрам технических средств}
    
    Для корректной работы программы необходимо вычислительное устройство с 64-разрядным процессором и достаточным объемом оперативной памяти для формирования колонoчных батчей и параллельной записи данных. Для типовых сценариев генерации рекомендуется наличие многоядерного процессора, не менее 8 ГБ оперативной памяти и дисковой подсистемы, допускающей запись файлов требуемого размера.
    

    \subsection{Требования к информационной и программной совместимости}
    
    На устройстве должна быть установлена 64-разрядная операционная система семейства Linux, обеспечивающая совместимую сборку и запуск программы. Для сборки и корректной работы программы должны быть доступны система сборки CMake, компилятор с поддержкой стандарта C++17, библиотека Apache Arrow, а также библиотеки, необходимые для используемых форматов хранения и подсистемы параллельного выполнения. Выходные данные программы должны быть совместимы с программными средствами, поддерживающими чтение соответствующих форматов хранения.
    
    \subsection{Требования к составу сетевых средств}
    
    Для базового сценария генерации с записью результатов на локальную файловую систему наличие доступа к сети не требуется. При использовании удаленных URI и объектных хранилищ у вычислительного устройства должен быть доступ к соответствующей сети передачи данных.

    \section{Порядок контроля и приемки}
    
    Контроль и приемка разработки осуществляются в соответствии с документом «Программа и методика испытаний».

    В ходе приемки должна проверяться корректность генерации таблиц набора данных TPC-H, соответствие числа строк выбранному scale factor, детерминированность результата при различных конфигурациях партиционирования и параллельного выполнения, а также корректность записи данных в поддерживаемые форматы хранения.
    
    \section{Технико-экономические показатели}
    
     На сегодняшний момент количество аналитических систем, движков хранения и исследовательских стендов, работающих с колонoчными форматами данных, растет с каждым днем. Для разработки, тестирования и сравнения таких систем требуется воспроизводимый источник синтетических данных, позволяющий быстро получать таблицы набора TPC-H в различных форматах хранения и с различными стратегиями записи. Предполагается, что данная программа позволит сократить затраты времени на подготовку тестовых наборов данных, упростить экспериментирование с форматами хранения и повысить удобство разработки и верификации аналитических систем.
